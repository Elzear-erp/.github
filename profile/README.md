## Français

Elz (le nom « Elzéard » étant déjà pris ailleurs) construit un cockpit de gestion pour
les PME françaises — devis, facturation (Factur-X), suivi de chantier, trésorerie, RH,
prospection — dans un seul outil, pensé mobile-first.

**La souveraineté n'est pas une option** : hébergement en Europe, aucune IA américaine
dans la boucle de production (modèles Mistral ouverts, auto-hébergés), isolement strict
des données par société cliente.

**Pourquoi cette organisation semble vide.** Les dépôts sous `Elzear-erp/*` sont privés
par construction : ils portent le code d'un produit qui manipule des devis, des
factures et des données clients réelles — pas un projet open source. Ce qui reste
consultable sans compte :
- le [site public](https://elzear-erp.github.io) — présentation, et le guide de
  démarrage de la démonstration officielle ;
- ce document.

**Contact** : recommandation privée, clients choisis — nom et domaine officiels pas
encore arrêtés ; en attendant, via la personne qui vous a orienté ici.

## English

Elz (the name "Elzéard" being already taken) builds a management cockpit for French
SMEs — quotes, invoicing (Factur-X), job-site tracking, cash flow, HR, prospecting — in
a single tool, mobile-first by design.

**Sovereignty is not optional**: hosted in Europe, no US AI in the production loop
(open Mistral models, self-hosted), strict per-client data isolation.

**Why this organization looks empty.** Repos under `Elzear-erp/*` are private by
construction: they carry the code of a product that handles real customer quotes,
invoices, and data — not an open-source project. What's visible without an account:
- the [public site](https://elzear-erp.github.io) — an overview, and the quick-start
  guide for the official demo;
- this document.

**Contact**: private referral, selected clients — official name and domain not
settled yet; in the meantime, through whoever pointed you here.
